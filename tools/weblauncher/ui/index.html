Setup

      
Your own copy of the game (version 13.0.5, with its update), the keys from your console and, optionally, its
        firmware (for the console's own fonts). The folders an emulator keeps are found by themselves.

      

        
        

        

      

      

        
        

        

      

      

        
        

        

      

      

        
        
      

      

        
        
      

      
      
Installing the build's packages asks for your password in a dialog (sudo). On SteamOS and on
        Bazzite and other image-based systems, run the setup in Desktop Mode the first time: SteamOS needs its system made
        writable first, and on an image-based system the packages may need a restart (docs/LINUX.md).
